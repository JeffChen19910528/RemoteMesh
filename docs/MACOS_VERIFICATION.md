# macOS 實機驗證清單

macOS 後端(CoreGraphics 擷取、CGEvent 注入、pbcopy/pbpaste 剪貼簿、權限檢查、TLS 伺服器角色)只有邏輯測試,**從未在真實 Mac 上執行**。這份清單列出必須在 Mac 上確認的項目,每項有「做法」與「通過的條件」。做完把結果填進最後的表格,再更新 `RELEASE_READINESS.md` 與 `PLATFORMS.md`。

需要:一台 Mac(Apple Silicon 用 `osx-arm64` 套件,Intel 用 `osx-x64`)、一台可連到同一個伺服器的 Windows 或 Linux 電腦、一個正在執行的伺服器(`docs/DEPLOYMENT.md`)。

## 0. 取得與啟動

1. 複製 `remotemesh-<版本>-osx-<架構>.tar.gz` 與 `SHA256SUMS-desktop.txt` 到 Mac,執行 `shasum -a 256 <檔案>`,與清單比對。**通過**:雜湊相同。
2. `tar xzf` 解開。`ls -l RemoteMesh.app/Contents/MacOS/` 與 `agent/`。**通過**:主程式與 `agent` 都有執行權限(`-rwxr-xr-x`)。
3. 對 `RemoteMesh.app` 按右鍵 → 打開(或 `xattr -dr com.apple.quarantine RemoteMesh.app`)。**通過**:視窗出現、顯示自己的短 ID;沒有崩潰對話框。
4. 在設定填入伺服器位址,重新啟動。**通過**:狀態顯示已上線。

## 1. 權限

1. 未授權任何權限時啟動。**通過**:程式明確顯示缺「螢幕錄製」與「輔助使用」兩項,不是靜默失敗。
2. 只授權「螢幕錄製」(系統設定 → 隱私權與安全性),重新啟動。**通過**:只顯示缺「輔助使用」。
3. 兩項都授權並重新啟動。**通過**:不再顯示缺權限。

## 2. 被控端(Mac 被別人控制)

從另一台電腦連到這台 Mac,Mac 上按「允許」。

| # | 項目 | 做法 | 通過的條件 |
|---|------|------|------------|
| 2.1 | 擷取 | 在 Mac 開一個純色視窗(例如全螢幕的紅色網頁) | 檢視端看到的是真實桌面與視窗,不是只有桌布;顏色正確(紅仍是紅) |
| 2.2 | Retina | 在 Retina 螢幕上看 | 畫面比例正確、不模糊到無法閱讀、不拉伸 |
| 2.3 | 滑鼠 | 檢視端把滑鼠移到畫面四角與中央、點擊 Dock 上的項目 | 游標落點與檢視端指的位置一致(誤差在數個像素內);點擊有效 |
| 2.4 | 鍵盤 | 在 Mac 開「文字編輯」,檢視端輸入英文、數字、方向鍵、Backspace、Return、Shift 大寫 | 文字與按鍵正確出現 |
| 2.5 | 修飾鍵 | 檢視端按 Windows 鍵+空白、Ctrl+C | Windows 鍵作為 Command 生效;Ctrl+C 預設是 Control(不會複製),符合 `CtrlActsAsCommand` 預設值 |
| 2.6 | 滾輪 | 檢視端滾動網頁 | 方向與距離合理 |
| 2.7 | 剪貼簿 | 雙向複製含引號、換行、中文的文字 | 內容逐字相同 |
| 2.8 | 外接螢幕 | 若有第二個螢幕 | 目前只擷取主螢幕;確認行為與文件相符 |
| 2.9 | 睡眠與鎖定 | 讓螢幕鎖定或睡眠 | 記錄行為(擷取是否中斷、是否能自動恢復);不得崩潰 |

## 3. 控制端(Mac 控制別人)

| # | 項目 | 通過的條件 |
|---|------|------------|
| 3.1 | 連到 Windows 或 Linux 的被控端,看到畫面 | 畫面連續更新,沒有色偏 |
| 3.2 | 在檢視視窗用滑鼠點擊、拖曳 | 對方游標位置與點擊正確 |
| 3.3 | 鍵盤 | 英文、數字、方向鍵、功能鍵正確;Mac 的 Command 對應到對方的 Windows 鍵或預期的鍵 |
| 3.4 | 中文輸入法開啟時打字 | 記錄行為(輸入法組字是否干擾);列為已知限制即可,不得崩潰 |
| 3.5 | 全螢幕與調整視窗大小 | 座標映射仍正確 |

## 4. 安全相關(最重要)

1. **TLS 伺服器角色**:Mac 當被控端時,對方連入。**通過**:連線成功,檢視端的傳輸安全顯示為 TLS 1.3(或 1.2 + ECDHE)。若握手失敗,記下完整錯誤訊息(不得退回不加密;這是設計上的要求)。
2. **安全碼**:兩端顯示相同的安全碼。
3. **金鑰**:重新啟動程式後仍是同一個裝置 ID(金鑰存放在鑰匙圈或資料夾;記下實際位置與權限)。「更換金鑰」成功,且之後仍能連線。
4. **封鎖**:在 Mac(被控端)對連線中的裝置按「封鎖」。**通過**:連線立刻結束;該裝置再要求時直接被拒、Mac 上不跳出詢問;「已封鎖的裝置」出現,解除後再被詢問。
5. **日誌**:找到程式的日誌或輸出,確認沒有私鑰、剪貼簿內容、工作階段密鑰。

## 5. 穩定性

- 連續連線 30 分鐘,記錄 CPU 使用率、記憶體(活動監視器)與畫面更新率。
- 中斷 Wi-Fi 10 秒再恢復:應自動重連並繼續。
- 關閉視窗再開:單一實例鎖正常(不會出現兩個)。
- 重複連線、斷線 20 次:無崩潰、無記憶體持續上升。

## 失敗時回報什麼

- 哪一項、macOS 版本、晶片(Apple Silicon 或 Intel)。
- 完整錯誤訊息或崩潰報告(「Console」或 `~/Library/Logs/DiagnosticReports`)。請先確認內容沒有個人資料再提供。
- 已知會在 Mac 上出現的候選問題:`CGDisplayCreateImage` 在新版 macOS 的行為(可能需要改用 ScreenCaptureKit)、權限在重新簽署後被重置、TLS 伺服器憑證的金鑰集(`EphemeralKeySet`)在 macOS 上的支援。
